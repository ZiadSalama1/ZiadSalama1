# 💫 About Me:
I'm an Embedded Linux Systems Engineer specializing in BSP layer integration, custom distribution development with the Yocto Project, and consumer device platforms like Smart TVs and set-top boxes. My work bridges the gap between hardware peripherals, low-level Linux internals, and production middleware architectures.<br>Core Skills & Technologies:<br>• OS & Build Systems: Embedded Linux, Yocto / OpenEmbedded, BitBake, AOSP, GCC/Clang Toolchains<br>• Languages: C, C++, Bash/Shell, Python<br>• Middleware & Systems: RDK, Android HAL, D-Bus, systemd, IPC mechanisms<br>• Debugging & Profiling: gdb, strace, valgrind, core dump analysis<br>• Tooling & DevOps: Docker, Git, CI/CD pipelines, SDK packaging and export
